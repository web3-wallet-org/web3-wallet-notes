
## 定义
以太坊是基于账户模型的智能合约平台，本质是状态机（State Machine），目标是支持去中心化应用（DApp）。

## 账户类型
- **EOA**（Externally Owned Account）：用户控制，有私钥
- **Contract Account**：由代码控制，无私钥

账户结构：balance / nonce / code / storage

## 地址生成
私钥 -> 公钥 -> keccak256(公钥) -> 取后 20 字节

## 与 BTC 的区别
BTC 用 UTXO 模型，ETH 用 Account 模型，所有状态全局共享，支持智能合约。
