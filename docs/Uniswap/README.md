# Uniswap 学习指南

> **核心定位**: Uniswap 是以太坊上最大的去中心化交易所（DEX），采用自动做市商（AMM）模型。从 V2 的恒定乘积到 V3 的集中流动性，再到 V4 的 Hooks 架构，每一代都在解决前代的核心痛点。

---

## 📊 V2 vs V3 vs V4 核心区别一览

| 维度 | **V2** | **V3** | **V4** |
|------|--------|--------|--------|
| **发布时间** | 2020年5月 | 2021年5月 | 2025年（计划） |
| **核心创新** | 恒定乘积 AMM | 集中流动性 | Hooks 架构 |
| **AMM 公式** | x × y = k | x × y = k（区间内） | x × y = k（可定制） |
| **流动性范围** | 0 → ∞（全范围） | 自定义价格区间 | 自定义 + Hooks 控制 |
| **资金效率** | 低（分散在无限区间） | 高（集中在活跃区间） | 极高（+ Hooks 优化） |
| **手续费率** | 固定 0.3% | 可选 0.05% / 0.3% / 1% | 完全可定制（通过 Hooks） |
| **Gas 成本** | 较低 | 较高（复杂数学计算） | 更低（Singleton 架构） |
| **闪贷** | 支持 | 支持 | 支持（+ Hooks 扩展） |
| **预言机** | TWAP（时间加权） | 改进版 TWAP | 可扩展预言机 |
| **核心痛点** | 资金效率低 | 复杂度高、LP 风险大 | 架构更灵活 |
| **适用场景** | 学习基础 AMM | 生产环境主流 | 未来趋势、定制化需求 |

---

## 🔑 一句话概括

- **V2**: **"简单但浪费"** — 流动性均匀分布在 0 到无穷大，大部分资金闲置
- **V3**: **"高效但复杂"** — LP 可以集中流动性在特定价格区间，资金利用率提升 4000 倍
- **V4**: **"灵活且强大"** — 引入 Hooks 机制，允许开发者自定义 AMM 逻辑，架构统一（Singleton）

## 📊 当前市场使用情况

### 哪个版本用得最多？

**答案是: V3 占据绝对主导地位！**

| 版本 | 市场占比 | TVL (锁仓量) | 日交易量 | 使用场景 |
|------|---------|-------------|---------|---------|
| **V3** | **~85%** | ~$4-5B | ~$1-2B | ✅ 生产环境主流 |
| **V2** | ~10% | ~$500M | ~$100M | ✅ 简单场景、学习 |
| **V4** | <1% | 测试阶段 | - | ⏳ 刚发布，生态早期 |
| **V1** | 0% | 0 | 0 | ❌ 已废弃 |

*(数据截至 2025 年，来源: DefiLlama)*

### 为什么 V3 是主流？

#### ✅ V3 胜出的原因

1. **资金效率极高**
   - LP 可以集中流动性，收益率比 V2 高 10-100 倍
   - 吸引大量专业做市商和机构

2. **手续费灵活**
   - 稳定币对: 0.05%（USDC/USDT）
   - 主流币对: 0.3%（ETH/USDC）
   - 长尾代币: 1%（高风险代币）
   - 不同场景最优选择

3. **池子深度更深（对交易者更友好）**
   - **池子深度**: 指在某个价格区间内可用的流动性总量
   - **V3 优势**: 资金集中在活跃区间 = 相同资金量下，深度是 V2 的 10-100 倍
   - **实际效果**: 大额交易滑点更低、价格更稳定
   - **例子**: 1000 ETH 在 V3 的 $1900-$2100 区间，深度相当于 V2 的 10 万 ETH

4. **生态成熟**
   - 所有主流 DEX 前端都支持 V3
   - 工具完善（SDK、API、分析工具）
   - 大量文档和教程

5. **经过实战检验**
   - 2021 年发布，已运行 4 年
   - 处理过数十亿美元交易
   - 安全性得到验证

#### ❌ V2 为什么不主流了？

1. **资金效率太低**
   - LP 收益率远低于 V3
   - 专业做市商已迁移到 V3

2. **仍在使用的原因**
   - 简单易懂，适合新手
   - 某些场景不需要复杂功能
   - 部分老协议仍依赖 V2

#### ⏳ V4 为什么还没普及？

1. **刚发布（2025 年）**
   - 生态还在早期
   - 工具不完善
   - 文档和教程较少

2. **复杂度高**
   - Hooks 开发难度大
   - 需要深入学习才能掌握

3. **未来趋势**
   - 1-2 年后可能成为主流
   - 现在学习是抢占先机

## 💡 核心概念速查

### AMM 基础
- **流动性池（Pool）**: 两种代币的资金池
- **做市商（LP）**: 提供流动性赚取手续费
- **池子深度（Liquidity Depth）**: 某个价格区间内可用的流动性总量
  - 深度越大 → 大额交易滑点越低
  - V3 集中流动性 = 相同资金下深度提升 10-100 倍
- **滑点（Slippage）**: 实际成交价与预期价的偏差
- **无常损失（Impermanent Loss）**: LP 因价格波动产生的损失

### V2 核心
- **恒定乘积**: `reserve0 × reserve1 = k`
- **全范围流动性**: LP 资金分布在 0 → ∞
- **固定手续费**: 0.3%（27% 归协议，73% 归 LP）

### V3 核心
- **集中流动性**: LP 选择价格区间 [P_lower, P_upper]
- **Tick 系统**: 将价格区间离散化
- **手续费等级**: 0.05%（稳定币）、0.3%（主流）、1%（长尾）

### V4 核心
- **Singleton**: 所有池子共用一个合约
- **Hooks**: 自定义回调函数（swap/mint/burn 前后）
- **Flash Accounting**: 延迟结算，降低 Gas
- **原生 ETH**: 支持 ETH 直接交易（无需 WETH）
