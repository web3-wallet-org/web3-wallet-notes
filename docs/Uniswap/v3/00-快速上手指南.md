### Day 3: 学会选择价格区间

**学习目标**: 理解如何选择最优的流动性区间

**核心概念**:
```
当前价格: $2000

区间选择策略:
- 窄区间 ($1900-$2100): 高收益，高风险（容易超出区间）
- 中区间 ($1800-$2200): 平衡选择（推荐新手）
- 宽区间 ($1500-$2500): 低收益，低风险
```

**实战任务**:
1. 在 Uniswap V3 界面尝试添加流动性
2. 选择不同的价格区间，观察:
   - 预期 APY（年化收益率）
   - 价格超出区间的风险提示
3. **不要真的添加**，只是模拟操作

**工具推荐**:
- Uniswap V3 位置计算器: https://v3calculus.com/
- 查看当前价格: https://app.uniswap.org/#/pools

### Day 4: 理解手续费等级

**学习目标**: 为不同交易对选择合适的手续费等级

**手续费等级选择**:

| 等级 | 适用场景 | 例子 | Tick 间距 |
|------|---------|------|----------|
| **0.05%** | 稳定币对 | USDC/USDT, DAI/USDC | 10 |
| **0.3%** | 主流币对 | ETH/USDC, WBTC/ETH | 60 |
| **1%** | 长尾代币 | 新代币、低流动性 | 200 |

**实战任务**:
1. 查看 ETH/USDC 池子，确认手续费是 0.3%
2. 查看 USDC/USDT 池子，确认手续费是 0.05%
3. 思考：为什么稳定币对手续费低？

**答案**: 稳定币价格波动小，风险低，所以手续费低。如果手续费太高，套利者会把价格拉回锚定值。

### Day 5: 理解无常损失

**学习目标**: 评估做 LP 的真实风险

**关键公式**:
```
无常损失 = (提供流动性的价值) - (简单持有的价值)
```

**例子**:
```
初始: ETH = $2000，你提供 $1800-$2200 区间

情况 A: ETH 涨到 $3000
- 你的仓位 100% 变成 USDC
- 无常损失: ~15%

情况 B: ETH 跌到 $1000
- 你的仓位 100% 变成 ETH
- 无常损失: ~25%
```

**降低无常损失的方法**:
1. ✅ 选择宽区间（但降低收益率）
2. ✅ 主动管理（价格接近边界时调整）
3. ✅ 选择高交易量池子（手续费补偿损失）
4. ✅ 对冲策略（在其他平台做反向仓位）

**实战任务**:
使用无常损失计算器: https://defillama.com/yields/impermanent-loss
输入不同价格场景，观察损失变化

### Day 6: 实战操作（测试网）

**学习目标**: 在测试网上完成完整操作

**准备工作**:
1. 安装 MetaMask
2. 切换到 Sepolia 测试网
3. 领取测试代币: https://sepoliafaucet.com/

**操作步骤**:

#### 步骤 1: 获取测试代币
```
1. 访问 https://app.uniswap.org/#/swap
2. 切换到 Sepolia 测试网
3. 用测试 ETH 兑换测试 USDC
```

#### 步骤 2: 添加流动性
```
1. 进入 https://app.uniswap.org/#/add
2. 选择 ETH/USDC 交易对
3. 选择手续费等级: 0.3%
4. 设置价格区间: 当前价格的 ±10%
5. 输入数量，确认添加
```

#### 步骤 3: 查看仓位
```
1. 进入 https://app.uniswap.org/#/pools
2. 查看你的 NFT 仓位
3. 观察手续费累积
```

#### 步骤 4: 移除流动性
```
1. 选择你的仓位
2. 点击"Remove Liquidity"
3. 确认移除
```

**记录你的操作**:
- 添加了多少流动性？
- 选择了什么价格区间？
- 1 小时后累积了多少手续费？
- 移除时是否有无常损失？

### Day 7: 深入学习开发

**学习目标**: 理解如何在智能合约中与 V3 交互

**核心合约**:
```
Factory         - 创建 Pool
Pool            - 交易池（swap、流动性）
PositionManager - NFT 仓位管理
Router          - 用户交互入口
Quoter          - 价格查询
```

**实战练习**: 使用 Hardhat 或 Foundry

#### 练习 1: 查询价格
```javascript
// 查询 ETH/USDC 当前价格
const pool = await ethers.getContractAt(
  "IUniswapV3Pool",
  "0x8ad599c3A0ff1De082011EFDDc58f1908eb6e6D8" // ETH/USDC 0.3%
);

const slot0 = await pool.slot0();
console.log("sqrtPriceX96:", slot0.sqrtPriceX96.toString());
```

#### 练习 2: 添加流动性（合约层面）
```solidity
// 在你的智能合约中添加流动性
import "@uniswap/v3-periphery/contracts/interfaces/INonfungiblePositionManager.sol";

INonfungiblePositionManager positionManager = 
    INonfungiblePositionManager(0xC36442b4a4522E871399CD717aBDD847Ab11FE88);

// 创建仓位
positionManager.mint({
    token0: WETH,
    token1: USDC,
    fee: 3000,
    tickLower: -887220,
    tickUpper: 887220,
    amount0Desired: 1 ether,
    amount1Desired: 2000e6,
    amount0Min: 0,
    amount1Min: 0,
    recipient: address(this),
    deadline: block.timestamp + 300
});
```

## 💡 常见误区

### ❌ 误区 1: 区间越窄越好
**真相**: 窄区间收益高，但容易被踢出区间。新手建议选 ±10-20% 的中等区间。

### ❌ 误区 2: 不用管无常损失
**真相**: 无常损失是 LP 的主要风险，必须评估。高手续费可以补偿，但要计算清楚。

### ❌ 误区 3: 添加后就不用管了
**真相**: V3 需要主动管理。价格接近边界时，要考虑调整区间或移除流动性。

### ❌ 误区 4: 所有池子都能赚钱
**真相**: 只有高交易量、低波动的池子才适合做 LP。冷门池子手续费少，无常损失大。
