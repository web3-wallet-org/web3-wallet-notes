## 📚 课程概述

这是一门**实战型课程**，带你从零开始构建一个完整的 Uniswap V3 DEX，包括：

- ✅ 智能合约开发（Solidity）
- ✅ 合约测试和部署（Foundry/Forge）
- ✅ DEX 设计与数学原理
- ✅ 前端开发（React + MetaMask）

### 里程碑 2: 第二次 Swap 🔄

**核心任务**: 实现双向交易，让 DEX 真正可用

**你将学到**:
1. **Solidity 数学库** - 处理定点数和平方根

**技术要点**:
- 使用第三方数学库（处理整数除法）
- Swap 方向选择（zeroForOne）

### 里程碑 3: 跨 Tick Swap 📊

**核心任务**: 支持多价格区间，实现真正的集中流动性

**你将学到**:
1. **多区间流动性** - 在不同价格范围提供流动性
2. **跨 Tick 交易** - 当价格跨越区间时如何处理
3. **流动性计算** - 在合约中动态计算流动性
4. **滑点保护** - 防止价格操纵和 MEV 攻击
5. **定点数深入** - 更多数学细节

**技术要点**:
- Mint 函数支持不同价格范围
- Swap 函数跨越多个 Tick
- 滑点保护机制（amountOutMinimum）
- 定点数运算

**实战项目**:
- 更新 mint 支持多区间
- 更新 swap 支持跨 Tick
- 实现滑点保护
- 更新前端允许选择区间

**GitHub 代码**: https://github.com/Jeiwan/uniswapv3-code/tree/milestone_3

**学习建议**: 4-5 天（核心里程碑）
- 第 1 天：理解多区间流动性
- 第 2 天：实现跨 Tick Swap（重点）
- 第 3 天：实现滑点保护
- 第 4 天：测试跨区间场景
- 第 5 天：更新前端

**链接**: https://learnblockchain.cn/article/23807?course_id=100

## 💡 学习建议

### 1. 循序渐进
不要跳过里程碑，每个里程碑都建立在之前的基础上。

### 2. 动手实践
- 克隆代码库：`git clone https://github.com/Jeiwan/uniswapv3-code`
- 切换到对应分支：`git checkout milestone_1`
- 自己写代码，不要只复制粘贴

### 3. 理解数学
V3 的核心是数学，花时间理解：
- 平方根价格（sqrtPriceX96）
- 定点数运算
- 流动性计算公式

### 4. 写测试
每个里程碑都要写单元测试：
```bash
forge test
```

### 5. 遇到问题
- 查看 GitHub Discussion
- 查阅官方文档
- 在课程页面提问
