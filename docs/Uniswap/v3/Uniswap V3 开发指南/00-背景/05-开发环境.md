## 🛠️ 我们要用哪些工具？

### 技术栈概览

```
智能合约:
  ├─ Solidity (编程语言)
  ├─ Foundry (测试框架)
  └─ Anvil (本地节点)

前端:
  ├─ React (用户界面)
  ├─ Ethers.js (与合约交互)
  └─ MetaMask (钱包)
```

---

## 💻 智能合约开发工具

### Foundry（推荐）

**为什么选 Foundry？**

1. **用 Solidity 写测试**（不用 JavaScript）
2. **测试速度极快**（不启动节点）
3. **功能强大**（可以模拟各种场景）

**Foundry 包含三个工具**:

```
Forge  → 测试框架（写测试用）
Anvil  → 本地节点（运行合约用）
Cast   → 命令行工具（调试用）
```

### 安装 Foundry

```bash
# Linux/Mac:
curl -L https://foundry.paradigm.xyz | bash
foundryup

# Windows (WSL):
同上
```

## 🌐 前端开发工具

### Ethers.js

**作用**: JavaScript 库，用来和以太坊交互。

**常用功能**:
```javascript
// 连接钱包
const provider = new ethers.providers.Web3Provider(window.ethereum);

// 获取余额
const balance = await provider.getBalance(address);

// 调用合约
const contract = new ethers.Contract(address, abi, signer);
const result = await contract.swap(...);
```

### MetaMask

**作用**: 浏览器钱包，用来签名交易。

**安装**: https://metamask.io/

### React

**作用**: 前端框架，构建用户界面。

我们提供一个模板，不需要精通 React。

## 📁 项目结构

```
uniswapv3-clone/
├── src/          # 智能合约
├── test/         # 测试文件
└── ui/           # 前端应用
```

### 初始化项目

```bash
# 创建项目
forge init uniswapv3-clone

# 初始化前端
cd uniswapv3-clone
npx create-react-app ui
```
