## 🎯 课程目标

我们要构建一个 **Uniswap V3 的简化版本**，包含：

1. ✅ 核心池合约（流动性管理 + 交易）
2. ✅ 工厂合约（创建新池子）
3. ✅ 路由器（简化交易流程）
4. ✅ 报价器（查询价格）
5. ✅ NFT 管理器（仓位 NFT 化）
6. ✅ 前端界面（与合约交互）

---

## 📦 智能合约清单

### 1. UniswapV3Pool（核心）

**作用**: 实际的交易池

**功能**:
- 添加/移除流动性
- 执行 Swap
- 计算费用

**代码量**: ~500 行 Solidity

### 2. UniswapV3Factory（工厂）

**作用**: 创建和管理池子

**功能**:
- 部署新的池子
- 记录所有池子地址

### 3. UniswapV3Manager（路由器）

**作用**: 简化用户操作

**功能**:
- 一键交易（不用直接调用 Pool）
- 多跳交易（A → B → C）

### 4. UniswapV3Quoter（报价器）

**作用**: 查询交易价格（不执行交易）

**功能**:
- 查询预期输出量
- 查询滑点

### 5. UniswapV3NFTManager（NFT 管理器）

**作用**: 将流动性仓位转为 NFT

**功能**:
- 铸造仓位 NFT
- 管理 NFT 仓位
- 收取手续费
