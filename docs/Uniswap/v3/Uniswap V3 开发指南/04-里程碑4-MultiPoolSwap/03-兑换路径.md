# 03 兑换路径

原文：<https://learnblockchain.cn/article/23811?course_id=100>

这一节讲 `Path`。

先记住一句话：

```text
Path 是多池交易的路线图。
```

如果用户想从 WETH 换到 WBTC，但没有直接池，系统可能要走：

```text
WETH -> USDC -> USDT -> WBTC
```

这条路不能只停留在前端脑子里，合约也必须看得懂。`Path` 就是把这条路线编码成合约能处理的数据。

## 这节在解决什么

多池交易要连续经过多个 Pool。

每经过一个 Pool，合约都需要知道三件事：

```text
输入 token
tickSpacing
输出 token
```

比如：

```text
WETH, 60, USDC
USDC, 10, USDT
USDT, 60, WBTC
```

这三段连起来，就是完整路径。

## 为什么路径里不放 Pool 地址

因为上一节已经有 `Factory + CREATE2 + PoolAddress` 了。

只要知道：

```text
token0
token1
tickSpacing
```

就能算出 Pool 地址。

所以路径没必要直接存 Pool 地址。路径只需要存“能推导出 Pool 地址的参数”。

这让路径更通用，也让 Manager 可以自己找池子。

## 路径长什么样

人能读懂的路径是：

```text
WETH -> USDC -> USDT -> WBTC
```

合约需要的路径是：

```text
WETH, 60, USDC, 10, USDT, 60, WBTC
```

它的规律是：

```text
token, tickSpacing, token, tickSpacing, token ...
```

每两个 token 中间夹一个 `tickSpacing`，表示这两个 token 之间要走哪个精度的 Pool。

## 为什么路径是 bytes

Solidity 里把路径编码成 `bytes`，不是为了好看，而是为了紧凑。

每个地址是 20 字节。

`tickSpacing` 是 `uint24`，也就是 3 字节。

所以一段 Pool 参数：

```text
tokenIn + tickSpacing + tokenOut
```

长度是：

```text
20 + 3 + 20 = 43 字节
```

多段路径就是继续拼接：

```text
20 字节 token
3 字节 tickSpacing
20 字节 token
3 字节 tickSpacing
20 字节 token
...
```

## Path 库要提供什么能力

`Path` 库的任务不是做 swap，而是帮合约读懂路径。

它主要提供这些能力：

1. `numPools`：算路径里有几个 Pool。
2. `hasMultiplePools`：判断是不是还有多个 Pool 没处理。
3. `getFirstPool`：取出路径开头的第一段 Pool。
4. `skipToken`：跳过已经处理的一段，进入下一段。
5. `decodeFirstPool`：把第一段解码成 `tokenIn`、`tokenOut`、`tickSpacing`。

## skipToken 为什么不是删掉整个 Pool

这个点容易绕。

假设路径是：

```text
WETH, 60, USDC, 10, USDT
```

第一段是：

```text
WETH, 60, USDC
```

处理完第一段后，下一段应该是：

```text
USDC, 10, USDT
```

所以不能把 `WETH, 60, USDC` 全删掉。因为 `USDC` 既是第一段的输出 token，也是第二段的输入 token。

真正要跳过的是：

```text
WETH, 60
```

保留 `USDC`，让它成为下一段的起点。

这就是 `skipToken` 的核心。

## 人话版理解

`Path` 就像导航路线。

它不是车，也不是路本身。它只告诉系统：

```text
第一段走哪里
第二段走哪里
第三段走哪里
```

Manager 每次只看路线的第一段，执行完以后把路线往前推进一格。

这个过程像这样：

```text
看第一段：WETH -> USDC
执行 swap
路径前进：USDC -> USDT
执行 swap
路径前进：USDT -> WBTC
执行 swap
结束
```

## 你要记住

- `Path` 是多池 swap 的路线编码。
- 路径不是只存 token，还要存 `tickSpacing`。
- 路径里不需要 Pool 地址，因为 Pool 地址可以计算出来。
- 单池交易也可以用 Path 表示，只是路径里只有一个 Pool。
- `skipToken` 要保留中间 token，因为它是下一段的输入 token。
- `Path` 库本身不交易，只负责读路径、切路径、解码路径。
