# 02 输出数量计算

这一节只解决一个问题：

> 当用户卖出 `token0` 时，池子要如何算出新价格和输出数量？

在本课程的 ETH/USDC 例子里，这就是：

- 卖 ETH
- 买 USDC

## 为什么前一里程碑还不够

上一阶段你已经有了“卖 `token1`、买 `token0`”的公式。  
但真实的 swap 必须双向都支持，所以现在要把另一半也补上。

## 这一节只记住两个结论

### 1. 先算价格，再算输出

V3 里不是“直接用一个比例算 amountOut”，而是：

```text
输入 amountIn
-> 推动 sqrtP 变化
-> 得到新的 sqrtP
-> 再根据前后价格差计算 amountOut
```

### 2. 卖 `token0` 时，价格会下降

如果是 `token0 -> token1`：

- 池子收到 `token0`
- 池子付出 `token1`
- 当前价格向下移动

## 关键公式

卖 `token0` 时，新价格的核心公式是：

```text
sqrtP_next = sqrtP * L / (amount0 * sqrtP + L)
```

如果你第一眼看不懂，可以先把它改写成更像人话的样子：

```text
sqrtP_next = sqrtP / (1 + amount0 * sqrtP / L)
```

这样更容易看出它的意思：

- `sqrtP` 是当前价格位置
- `amount0` 是这次卖进来的 `token0`
- `L` 是池子的“抗推能力”

工程上你可以直接把它理解成：

> 新价格位置 = 当前价格位置 / (1 + 这次卖单的价格冲击)

其中：

```text
价格冲击 ≈ amount0 * sqrtP / L
```

所以这条公式本质上只是在表达：

- 你卖进来的 `token0` 越多，价格冲击越大，`sqrtP_next` 越小
- 池子的流动性 `L` 越大，价格越不容易被推走

一句话记忆：

> 用户卖 `token0`，就是在把价格往下压；这条公式是在算“会被压到哪里”。

你不需要背整套推导，但一定要记住它表达的含义：

- 输入越多，价格移动越大
- 流动性 `L` 越大，价格越不容易被推动

## 为什么这公式重要

因为后面所有链上 swap 计算，都会围绕这个思路展开：

- 找到本次输入能把价格推到哪里
- 再根据前后价格变化反推出输出数量

## 用一句话理解输出数量

输出数量不是凭空算出来的，而是：

> 价格从旧位置移动到新位置后，区间内两种 token 余额变化的结果。

## 这节真正想让你学会什么

- 双向 swap 需要两套方向相关的价格公式。
- V3 的第一步永远是算价格移动。
- 流动性决定价格对输入量的敏感程度。

- 为什么卖 `token0` 时价格不是上升而是下降？
- 为什么 V3 不是直接 `amountIn * price = amountOut`？
