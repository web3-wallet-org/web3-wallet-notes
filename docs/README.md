## 知识状态

内容按成熟度分为三种：

| 状态 | 放置位置 | 含义 |
| --- | --- | --- |
| 捕获 | `inbox/` | 新问题、零碎结论、待验证材料 |
| 整理 | 主题目录 | 已形成结构，但可能仍需源码或实验验证 |
| 掌握 | 主题文档 + 实验 | 能解释原理、失败场景和方案取舍 |

## 新增内容流程

1. 不确定归属时，先在 `inbox/` 建一条短笔记。
2. 找到稳定主题后，合并进对应文档，避免长期积累重复文章。
3. 需要验证的结论在 `src/` 或 Web3 Wallet Labs 中编写最小实验。
4. 在文档中链接实验，在实验 README 中反向链接原理文档。
5. 最后补充生产失败场景、技术取舍和面试回答。

## 内容边界

- 本仓库保存最终知识结论、架构分析和与主题紧密相关的实验。
- 通用钱包小实验放在 Web3 Wallet Labs。
- 外部文章只作为资料来源，不直接替代自己的结论。
- 同一结论只保留一个主要入口，其他位置通过链接引用。
