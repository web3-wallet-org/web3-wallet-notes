# Web3 Learning

这是一个用于学习 Web3 的仓库，包含两部分：

- `docs/`：学习文档与笔记
- `src/`：代码实践（合约与脚本）

## 学习节奏建议

1. 先在 `docs/` 写清楚原理与流程。
2. 再在 `src/` 做最小可运行验证。
3. 每学完一个主题，补一条总结到文档。

## 目录结构

```text
web3-learning/
├─ README.md
├─ docs/
│  ├─ 学习笔记.md
│  └─ Web3基础.md
├─ src/
│  ├─ contracts/
│  └─ scripts/
└─ .gitignore
```
